Roko's Basilisk

Roko's Basilisk is a first-person shooter with roguelike elements that adapts to the player's performance. Using constraint satisfaction techniques, the game analyzes player stats after each level to dynamically generate new levels and adjust enemy behavior through behavior trees. The result is a personalized experience where each playthrough evolves based on the player's strengths and weaknesses.

Otaku Oracle

OtakuOracle is a manga search engine designed to help users easily discover and explore titles based on criteria such as author, genre, and themes. Inspired by platforms like MyAnimeList, it provides a clean, intuitive interface with dynamically generated pages for detailed manga information. The project emphasizes fast, user-friendly search functionality and a modular design, making it easy to navigate and expand.
